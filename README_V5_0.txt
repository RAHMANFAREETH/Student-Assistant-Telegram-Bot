STUDENT ASSISTANT BOT V5.0
SMART STUDY INSIGHTS
==========================

🧠 SMART STUDY INSIGHTS
-----------------------
Analyzes existing student data by subject.

It looks at:
- pending assignments
- overdue assignments
- assignments due within 7 days
- quiz scores
- flashcard mastery
- attendance
- study minutes from last 7 days
- revision progress
- grade-point results
- exams within 14 days


🚦 SUBJECT HEALTH
-----------------
Each subject receives a rule-based score:

80–100  🟢 Strong
60–79   🟡 Watch
40–59   🟠 At Risk
0–39    🔴 High Risk

This score is only a study-planning indicator.
It is NOT an official academic grade.


🎯 WHAT SHOULD I STUDY?
-----------------------
Ranks subjects that need attention and gives
practical recommendations such as:

- Finish overdue assignments first.
- Review weak quiz topics and retest.
- Review flashcards.
- Catch up missed classes.
- Start a focused study session.
- Complete pending revision tasks.
- Create a revision plan before an exam.


📅 WEEKLY REVIEW
----------------
Shows:

- total study minutes over the last 7 days
- overdue assignments
- assignments due within 7 days
- number of strong subjects
- number of at-risk subjects
- strongest subject
- subject needing the most attention


COST
----
No paid AI.
No external API.
No new Python dependency.
No new SQL table.

V5.0 works entirely from data already stored
inside the Student Assistant Bot.
