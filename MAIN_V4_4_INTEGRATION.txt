STUDENT ASSISTANT BOT V4.4 INTEGRATION
======================================

1) Copy these files into the project root:

timetable.py
study_planner.py
study_analytics.py


2) Run v4_4_planner_timetable.sql inside Supabase SQL Editor.

IMPORTANT:
The SQL uses your existing Supabase Vault secret:

telegram_bot_token

The study session Cron checks every minute.


3) Add imports to main.py:

from timetable import register_timetable_handlers
from study_planner import register_study_planner_handlers


4) Add these two buttons to show_main_menu():

types.KeyboardButton("🗓 Timetable"),
types.KeyboardButton("⏱ Study Planner"),
