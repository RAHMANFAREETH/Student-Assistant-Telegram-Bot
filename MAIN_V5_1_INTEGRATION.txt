STUDENT ASSISTANT BOT V5.1
SMART NOTIFICATIONS CENTER
==========================

1) Copy into project root:

notification_preferences.py


2) Run this SQL:

v5_1_smart_notifications.sql

inside Supabase SQL Editor.


3) IMPORTANT

The SQL expects your existing Supabase Vault secret:

telegram_bot_token

Do NOT paste your Telegram token into SQL.


4) Add import to main.py:

from notification_preferences import (
    register_notification_preference_handlers
)


5) Add main-menu button:

types.KeyboardButton("🔔 Smart Notifications"),
