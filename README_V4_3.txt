STUDENT ASSISTANT BOT V4.3
STUDY MATERIALS + SMART DOCUMENT STUDY
======================================

FEATURES
--------

📚 STUDY MATERIALS
- Upload PDF
- Upload DOCX
- Upload TXT
- Link material to a subject
- Extract document text
- OCR fallback for scanned PDFs
- Save extracted text in Supabase
- List saved materials
- Read material text
- Search all saved materials
- Delete material

🧾 EXTRACTIVE SUMMARY
- No paid AI API required
- Summary is made only from sentences in the uploaded material
- Does not invent external facts
- Language-agnostic sentence/word scoring
- Best for lecture notes and text-heavy documents

✨ KEY POINTS
- Extracts up to 10 important sentences
- Uses the uploaded material only

📊 DASHBOARD UPDATE
- Study Materials count added
- Flashcard statistics retained

LIMITS
------
Maximum extracted text stored per material:
100,000 characters

For scanned PDFs:
OCR_SPACE_API_KEY must be configured.

This phase does not create generative AI summaries.
A future optional AI Study Assistant can be added separately.
