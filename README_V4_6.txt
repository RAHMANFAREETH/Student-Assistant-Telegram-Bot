STUDENT ASSISTANT BOT V4.6
==========================

📝 EXAM PLANNER
---------------
- Add exams by subject
- Exam date and time
- Optional location
- Optional notes / syllabus coverage
- Upcoming exams list
- Delete exams
- Automatic Telegram alerts:
  • within 7 days
  • within 24 hours
  • within 1 hour

✅ ATTENDANCE TRACKER
---------------------
- Mark Present
- Mark Absent
- Mark Late
- Mark Excused
- One attendance record per subject per date
- Re-marking the same day updates the record
- Subject attendance history
- Attendance percentage

Attendance percentage currently counts:
- Present = attended
- Late = attended
- Absent = not attended
- Excused = included in total but not counted as attended

🎯 STUDY GOALS
--------------
- Create goals
- Link goal to subject
- Optional description
- Optional target date
- Active goals
- Mark goal completed
- Completed goals history
- Delete goals

FREE ARCHITECTURE
-----------------
No new paid API.
No new Python dependency.
Exam alerts use Supabase Cron + Telegram API.
