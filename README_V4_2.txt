STUDENT ASSISTANT BOT V4.2

NEW FEATURES
============

🧠 FLASHCARDS
- Add flashcards
- Link to a subject
- List flashcards
- Delete flashcards
- Study mode
- Show-answer button
- Mark "I knew it"
- Mark "Practice again"
- Automatic mastery tracking

Mastery rule:
- at least 3 correct reviews
- correct reviews >= 2x wrong reviews

❓ QUIZ ENGINE
- Quizzes generated from saved flashcards
- Multiple-choice questions
- 4 options
- 5-question quiz by default
- Immediate correct/wrong feedback
- Quiz history
- Score saved to Supabase

Requirements for a subject quiz:
- at least 4 flashcards
- at least 4 different answers

📈 STUDY PROGRESS
- Total flashcards
- Mastered flashcards
- Learning flashcards
- Mastery percentage
- Quiz attempts
- Average quiz score
- Best quiz score
- Completed assignments
- Pending assignments

FREE ARCHITECTURE
=================
No AI API is required.
No additional paid service is required.
Uses the existing Render + Supabase setup.
