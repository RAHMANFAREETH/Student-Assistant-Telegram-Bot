STUDENT ASSISTANT BOT V5.0
SMART STUDY INSIGHTS
====================

V5.0 is a milestone release.

It adds:
- Smart Study Insights
- Subject Health Score
- What Should I Study?
- Weekly Study Review


1) Copy into project root:

smart_insights.py


2) NO SQL REQUIRED.

V5.0 reads your existing tables:
- subjects
- assignments
- quiz_attempts
- flashcards
- attendance_records
- study_sessions
- revision_plans
- revision_tasks
- course_results
- exams


3) Add import to main.py:

from smart_insights import register_smart_insight_handlers

types.KeyboardButton("🧠 Smart Insights"),

10) HEALTH SCORE

Starts from 100.

Possible deductions include:
- overdue assignments
- assignments due soon
- low quiz average
- low flashcard mastery
- low attendance
- little/no study time
- exam approaching

This is a rule-based study score.
It is not a university grade and not a medical/psychological assessment.


11) NO PAID AI API

V5.0 uses only:
- existing Supabase data
- Python rules/calculations
